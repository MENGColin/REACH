# Release Checklist

- [ ] No API keys, host passwords, SSH keys, or credentials are committed.
- [ ] No model weights, checkpoints, or run logs are committed.
- [ ] No raw guideline PDFs or proprietary evidence files are committed.
- [ ] No raw patient records are committed.
- [ ] README numbers match the submitted manuscript snapshot.
- [ ] Dataset URL points to a versioned dataset release, not this code repository.
- [ ] The dataset card explains data provenance, expert audit, intended use, and limitations.
- [ ] The code release includes a license and citation file.
- [ ] Examples are clearly illustrative and non-clinical.
